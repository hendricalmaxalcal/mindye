HIGH LAYOUT
React (Vite) front end  ──►  Firebase Auth      (login, roles)
                        ──►  Firestore          (products, sales, stock, users)
                        ──►  Firebase Hosting   (deploy)
                        (optional later: Cloud Functions for reports and safeguards)
Barcode scanner (USB/Bluetooth) ──► acts as a keyboard ──► useBarcodeScanner hooks

MAIN FLOWS
Sale: scan barcode → look up products/{barcode} 
→ add to cart (repeat scan adds quantity) 
→ checkout 
→ one transaction reduces stock and creates the sales document 
→ print receipt.

Receiving: scan barcode 
→ if known, enter quantity received; if unknown, open the new-product form 
→ confirm → one transaction increases stock and creates the stockReceipts document.
